# Roadmap status

Life now ships the v3 local-first data model, canonical taxonomy flow, derived life list, unified observation filters, Quick Add, trips, venues/visits, collections, taxonomy/exploration, discovery targets, geography, statistics, milestones, responsive navigation, PWA assets, IndexedDB media abstraction, JSON/CSV portability and regression coverage.

Known intentional limitations: remote taxonomy denominators are not fabricated where incomplete; the map uses a paid-service-free bounded geographic view; photo media storage is isolated behind an IndexedDB abstraction and is not embedded in JSON localStorage.
